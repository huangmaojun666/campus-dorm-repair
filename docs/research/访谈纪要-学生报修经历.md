# 学生报修体验访谈纪要

本次访谈了两位同学，了解他们宿舍报修的经历，分别记为 A、B。

## 一、访谈问题

1. 最近一次报修是什么故障？你是怎么报的？
2. 报的时候你怎么跟宿管说明情况？会拍照吗？
3. 报完之后，你怎么知道有没有人处理、什么时候来修？
4. 师傅修完，你怎么知道修好了没有？
5. 如果后来发现没修好，你会怎么办？

## 二、访谈记录

### 受访者 A

**问 1：最近一次报修是什么故障？你是怎么报的？**

答：洗手台下面的管子渗水，地上有积水。我在宿舍楼的微信群里发了一段话说明情况，附了照片，然后 @ 宿管。宿管回了一句收到。


**问 2：报的时候你怎么跟宿管说明情况？会拍照吗？**

答：会拍照。文字写的是洗手台下面一直在渗、地上有积水，照片拍接口和地面的水迹。渗水的位置在洗手台下面，光线暗，得打着手电拍。群里人多，消息刷得快，她怕被漏掉，会再 @ 一遍。


**问 3：报完之后，你怎么知道有没有人处理、什么时候来修？**

答：只知道宿管回了收到，之后就等着，没有人再告诉她进度。


**问 4：师傅修完，你怎么知道修好了没有？**

答：师傅修完一般说一句好了就走。她的办法是当场放水、开关几次，再等一晚看。有一次她当场看是干的，第二天早上才发现接口下面还有水痕。


**问 5：如果后来发现没修好，你会怎么办？**

答：在群里再说一次，附一张新照片，等于把报修重走一遍，只是不用再描述故障。

### 受访者 B

**问 1：最近一次报修是什么故障？你是怎么报的？**

答：卫生间门把手松了，开门的时候晃得厉害。也是在宿舍楼的微信群里 @ 楼长，写一句卫生间门把手松动、麻烦报修一下，附一张门把手的照片。


**问 2：报的时候你怎么跟宿管说明情况？会拍照吗？**

答：拍了门把手的照片，文字就一句门把手松了、一拧就晃，没有再多说。


**问 3：报完之后，你怎么知道有没有人处理、什么时候来修？**

答：值班员回了句收到，之后没有消息，他也不知道什么时候来人。


**问 4：师傅修完，你怎么知道修好了没有？**

答：后续维修人员上门，把把手拆下来重新装了一遍，拧紧螺丝。修完他当场开关了几次门，把手不晃了，就认为修好了。


**问 5：如果后来发现没修好，你会怎么办？**

答：实际没有出现这种情况。修完以后把手没有再松，他也没有在群里再反馈，这件事就没有下文了。问到如果以后再松会怎么办，他说会先自己拧一下，不太想再报修，怕说了也没用。

## 三、两位受访者情况对照

| | A | B |
| --- | --- | --- |
| 报修时怎么说明 | 群里发文字 + 照片，再 @ 宿管 | 群里发一句 + 一张照片，@ 楼长 |
| 怎么确认 | 自己放水、开关、等一晚再看 | 当场开关几次门试试 |
| 没修好时 | 群里再说一次，重新发照片 | 未再出现，没有反馈 |
